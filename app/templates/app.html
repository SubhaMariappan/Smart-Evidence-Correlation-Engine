📖 SECE Workstation User Manual & Feature Guidance

Welcome to the Smart Evidence Correlation Engine (SECE). This forensic manual details every workspace view, operational module, and action control available to investigators and administrators.

🧭 Workspace Navigation & Module Directory

📊 Executive Brief (Overview):

Real-time case metrics grid displaying total evidence files, canonical entity profiles, cross-evidence relationships, and pending candidate matches, alongside the recent chain-of-custody activity trail.

📁 Case Manager:

Enables creating forensic case containers, indexing them by unique case number, switching active investigation scope, and updating investigation life-cycle status (OPEN, IN_PROGRESS, CLOSED).

📦 Evidence Vault:

Secure file intake repository. Supports raw file ingestion (.txt, .csv, .pdf), automated 64KB chunk streaming SHA-256 baseline hashing, live disk integrity re-verification, format parsing, and raw data inspection.

🏷️ Entity Catalog:

Directory of canonical normalized indicators (EMAIL, IPV4, PHONE, PERSON, LOCATION) with type filtering, mention frequency stats, and exact character offset contexts.

🕸️ Correlator Hub:

Discovers cross-evidence co-occurrences and evaluates candidate entity matches with confidence scoring. Investigators adjudicate matches with Accept or Reject decisions to train ground truth.

📜 Custody Ledger:

Immutable, append-only provenance record. Captures every pipeline run, evidence ingestion, parser execution, and status change with investigator UUID and UTC timestamps.

⚡ Granular Action Button Reference & Legend

⚡ Parse Runs the format-specific factory parser (TextParser, CSVParser, PDFParser) to extract text content and technical metadata into JSONB.
🏷️ Extract Runs high-precision deterministic regular expressions and NLP Named Entity Recognition (NER) to detect identities and record exact character start/end offsets.
🛡️ Verify Recomputes the cryptographic SHA-256 digest directly from the disk file and compares it to the original intake baseline hash to detect tampering or corruption.
👁️ Inspect Opens the parsed content and evidence inspection viewer with highlighted entity offsets and metadata overview.
⚡ Run Correlation Analyzes entity co-occurrences across multiple evidence files within the active case, scoring candidate matches and populating cross-file links.
Accept / Reject Human-in-the-loop review actions. Adjudicating candidate matches promotes them to verified relationships or dismisses false-positive inferences.

🛡️ Strict Two-Role Authority Model

ADMIN: Full system access, case creation, status updates, case closure/archival, and audit log inspection.
INVESTIGATOR: Active case analysis, evidence file intake, parser execution, indicator extraction, and candidate match adjudication.
